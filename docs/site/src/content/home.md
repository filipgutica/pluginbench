# Compare the guidance you give coding agents.

PluginBench runs the same coding tasks with and without your instructions, skills, or plugins, keeping the harness, model, and reasoning effort fixed.
Compare correctness, resource use, and the code each attempt adds to decide which guidance is worth using.

## Install

Install from a source checkout with Python 3.12 or later. The [installation instructions](../../../../README.md#install) cover setup and requirements.
