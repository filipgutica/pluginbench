# Changelog

## [0.5.0](https://github.com/filipgutica/pluginbench/compare/v0.4.0...v0.5.0) (2026-11-11)


### ⚠ BREAKING CHANGES

* leave a mean gate undetermined when an attempt has no value
* skip a measure that is broken on some tasks, and stop when a measure is ready on no task
* `run` takes the config or run directory only as a positional argument. `--config`, `--resume`, `--jobs`, `--guidance-name` and every evaluation flag (`--harness`, `--model`, `--reasoning`, `--guidance`, `--skill`, `--plugin`, `--tasks`, `--task`, `--measure`, `--review-*`, `--repeats`, `--seed`, `--timeout`) are removed; set them in the config. `run --dry-run` prints a summary instead of JSON unless `--json` is given. The plan's `baseline` key is now `vanilla`. examples/evaluation.yaml moved to src/pluginbench/evaluation.example.yaml.
